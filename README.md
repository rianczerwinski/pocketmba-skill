# pocketmba

Diagnose the business shape of an undertaking against relevant market alternatives, explaining which differences matter and why.

## Use

> Use PocketMBA to assess this venture’s market position, business model, and most consequential capability gaps.

The [skill instructions](SKILL.md) define the method and link its supporting references. Clone this repository as `pocketmba/` into your agent’s configured skill directory, preserving the complete folder. Discovery and invocation follow the host agent’s skill support.
